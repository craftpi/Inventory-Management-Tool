Lager-Modus

Hier siehst du auf einen Blick, was im Lager vorhanden ist. Die Zahl ist automatisch der Soll-Gesamtbestand des Vereins.

Zentraler Scan & Rückgabe-Knopf

Über den Knopf „⚡ Scannen & Rückgabe“ kannst du QR-Codes per Kamera scannen, NFC-Tags anhalten oder lose Teile ohne Code direkt per Namenssuche zurückbuchen.

🔢

Was die Mengen-Symbole bedeuten

5 = genaue Menge ∞ = unbegrenzt vorhanden - = ausreichend (vorhanden) - = bald nachbestellen
