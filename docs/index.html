👋 Kurz erklärt: So funktioniert das Lager-Tool

📦

Lager-Modus

Hier siehst du auf einen Blick, was im Lager vorhanden ist , nach Kategorien sortiert. Mit der Suche oben findest du Artikel, Orte oder Kategorien sofort.

📅

Event-Modus

Hier stellst du Packlisten für Resorts oder Veranstaltungen zusammen und siehst, ob im Lager genug Material für die Liste vorhanden ist.

🔢

Was die Mengen-Symbole bedeuten

Nicht jede Menge ist eine genaue Zahl – manchmal reicht ein grober Überblick:

5 = genaue Menge ∞ = unbegrenzt vorhanden - = ausreichend (grob geschätzt) - = bald nachbestellen
✏️

Bearbeiten-Modus

Über den Schalter „✏️ Bearbeiten" oben kannst du Mengen ändern, neue Artikel/Orte anlegen oder Kommentare hinzufügen. Ohne diesen Schalter kannst du nur ansehen, nichts kaputt machen.

📋

Entnahme-Protokoll

Nimmt jemand Material mit, wird das hier festgehalten: wer, was und wie viel – damit der Lagerbestand nachvollziehbar bleibt. Achtung es sind nicht alle Artikel per NFC Tag oder QR-Code erfassbar!

Zusätzliche Datenschutz-Infos

Dieses interne Verwaltungstool nutzt spezialisierte technische Dienstleister, um die Funktionalität zu gewährleisten:

1. Supabase (Datenbank & Login)
Wir nutzen Supabase (Supabase, Inc., USA) zur Speicherung der Bestandsdaten und für die Benutzeranmeldung. Hierbei wird technisch bedingt Ihre IP-Adresse übertragen und ein Authentifizierungs-Token im lokalen Speicher Ihres Browsers abgelegt.
Details: Supabase Privacy Policy

2. GitHub (Hosting)
Die Bereitstellung der Website-Dateien (HTML/JS) erfolgt über GitHub Pages (GitHub, Inc., USA). GitHub kann Protokolldaten über Zugriffe (IP-Adresse, Browser-Typ) erheben, um den Dienst sicher und zuverlässig bereitzustellen.
Details: GitHub Privacy Statement
